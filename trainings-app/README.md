# Trainings-App

Schneller Trainingslogger fürs iPhone (Webclip/PWA) mit Gewichtsassistent – läuft offline und nutzt Firebase im kostenlosen Spark-Plan.

> Die ausführliche Anleitung (Firebase einrichten, deployen, aufs iPhone holen) folgt am Ende des MVP.

## Schnellstart (lokal)

```bash
cd trainings-app
npm install
npm run web          # Entwicklungsserver im Browser
npm run check        # TypeScript + Theme-Check + Unit-Tests
npm run build:web    # statischer Export nach dist/ (inkl. Service Worker)
```
